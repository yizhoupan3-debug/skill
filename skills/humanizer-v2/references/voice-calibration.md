# 声音校准（Voice Calibration）

参考自 [blader/humanizer](https://github.com/blader/humanizer) 的 Voice Calibration v2.4.0+ 功能。

## 什么是声音校准

声音校准是让 AI 改写后的文本**匹配用户的个人写作风格**，而非产生通用的"干净"输出。它通过分析用户提供的写作样本来提取风格特征，然后指导 LLM 在改写时保持这些特征。

## 使用步骤

1. **让用户提供 2-3 段自己的写作样本**（不包含 AI 生成部分）
2. **分析以下维度**：

### 句式节奏
- 平均句子长度？是否有明显长短交替？
- 句子开头多样化程度？是否常用连接词开头？
- 段落长度和段落内句子数？

### 词汇选择
- 常用形容词的强度级别（保守 vs 强烈）？
- 学术术语的使用密度？
- 有没有习惯使用的过渡词和连接词？
- 有没有个人偏好词汇或回避词汇？

### 标点习惯
- 逗号使用密度高还是低？
- 是否常用破折号/冒号/分号？
- 引号的使用方式？

### 语气与声音
- 正式度（正式 ↔ 口语化）？
- 自信度（谨慎 ↔ 明确）？
- 直接的还是迂回的表达？

3. **应用校准规则**
   - 将分析结果嵌入 LLM 改写的系统提示中
   - 特别注明"保持以下特征不变：[从样本提取的 3-5 个核心特征]"

## 示例

用户样本特征：
```
- 句长平均 18-22 词，偶尔使用短句（<10 词）做强调
- 句子以连词开头占比约 20%（然而、此外、但）
- 使用"我们发现"而非"结果表明"作结论开头
- 避免使用"It is worth noting"类填充语
- 逗号使用密度中等，无破折号
- 术语使用精确但不密集
```

## 不适用范围

- 技术文档/代码注释（无需匹配个人风格）
- 用户明确要求完全客观的学术语言
- 用户无写作样本或拒绝提供时（使用默认改写强度）
