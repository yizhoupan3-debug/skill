# Math Explore

探索和发现新的数学性质、模式、关系和结构。这是"发现/探索"路径——
面对开放性问题时，通过计算实验、特例扫描、模式识别、文献调研来生成可检验的猜想。

**定位**：当你不确定某条数学路径通向何处时，从这里出发。

## 双Skill分工

| Skill | 路径 | 时机 |
|-------|------|------|
| `math-verify` | 验证/审查 | 审查既有推导的正确性 |
| **`math-explore` (本 skill)** | **发现/探索** | **未知性质，试探和发现** |

两者共享底层 `math-reasoning-harness` 工具链和 `$formal-verification` quality gate。
推导执行能力作为探索阶段的内部工作流（发现性质后如需形式证明，在本 skill 内完成）。

## When to use

- 你有一个表达式、函数或结构，想知道它有什么有趣的性质
- 你想测试一个数学猜想在特例下是否成立
- 你想推广已知结果到更一般的设定
- 你想通过数值实验寻找模式或规律
- 你想探索两个不同数学结构之间的关系
- 你想找某个不等式对于什么参数范围成立
- 你想渐近分析一个复杂表达式在边界情况下的行为
- 你要为某个问题的解决寻找思路/线索
- 你想检查某个数学性质在文献中是否已有描述
- 你发现了一个模式，想知道它是否是已知结果
- 适合如下的请求：
  - "这个函数在边界上有什么行为？"
  - "试试对这个不等式做推广"
  - "找一下这个表达式有什么对称性"
  - "当参数趋向什么值时这个式子有有趣的性质？"
  - "这个映射在什么条件下保持某种结构？"
  - "数值扫一下，看看有什么模式"
  - "从特殊情形推断一般形式"
  - "检查这个性质在文献中有没有人研究过"

## Do not use

- 用户需要审查已有推导的正确性（→ `$math-verify`）
- 用户已知明确目标、只需要计算执行（→ 当前上下文内联处理）
- 这是统计探索/数据模式而非数学性质（→ `$statistical-analysis`）
- 用户已经确定了猜想、需要严格的 checker-backed 证据（→ 在本 skill 内完成形式化验证，或通过 `$math-verify` 路径追加对抗式审查）

## Core workflow

```
输入问题/表达式/结构/不等式
    │
    ├── (S) 探索范围定义
    │   ├── 确定探索目标与评估标准
    │   ├── 识别可调参数与固定参数
    │   └── 确定"有趣"的定义（对称/单调/极值/边界行为/模式）
    │
    ├── (A) 静态分析
    │   ├── 符号化简探索——表达式结构解析
    │   ├── 渐近行为分析——∞ 和 0 邻域
    │   ├── 量纲探索——物理量纲一致性
    │   ├── 代数结构检测——对称性/周期性/因式分解/因子结构
    │   └── 特殊值探测——在已知特殊点（0,1,∞,对称点）求值
    │
    ├── (B) 数值探索
    │   ├── 随机采样——快速大规模数值试探
    │   ├── 结构化扫描——拉丁超立方 / 网格扫描覆盖参数空间
    │   ├── 边界扫描——参数边界附近的异常行为
    │   ├── 自适应精化——在兴趣区域加密采样
    │   └── 敏感性分析——参数变化对输出的影响
    │
    ├── (C) 猜想生成
    │   ├── 模式归纳：从数值模式到数学形式
    │   ├── 渐近形式猜测：从级数展开推测主导项
    │   ├── 对称/不变性推断：从结构线索推导代数约束
    │   └── 推广猜想：从特例推广到更一般条件
    │
    ├── (D) 猜想评估
    │   ├── 快速 falsify：用工具链测试猜想是否显然有反例
    │   ├── 覆盖密度评估：基于已测试的空间覆盖
    │   ├── 文献新颖性检查：搜索该猜想是否已被研究
    │   └── Promote 决策
    │
    └── (E) 文献调研（猜想验证或发现阶段调用）
        ├── 检查发现的模式是否已知结果
        ├── 寻找相关定理和已知性质
        └── 收集文献中的方法用于进一步探索
```

### 阶段详解

#### (S) 探索范围定义 — 明确探索什么

每次探索前先收口，避免无界搜索：

| 问题 | 产出 |
|------|------|
| 探索对象是什么？（表达式/函数/不等式/结构） | 形式化定义 |
| 目标是找什么？（边界行为/对称性/单调性/恒等式/极值） | 探索维度列表 |
| 哪些参数可调？范围是什么？ | 参数空间定义 |
| 评估标准是什么？（数值证据强度/解析可证性/新颖性） | 用户期望说明 |

**特别标注**：如果用户目标是"看这个表达式有哪些有趣性质"（无界探索），(S) 阶段应给出 3-5 个最有前景的探索方向供用户选择，不默认全量探测。

#### (A) 静态分析

| 操作 | 工具 | 产出 |
|------|------|------|
| 符号化简 | `math_sympy_simplify` | 表达式最简形式 |
| 因式分解 | `math_sympy_factor` | 因子结构 |
| 多项式展开 | `math_sympy_expand` | 展开形式 |
| 级数展开 | `math_sympy_series` | 局部近似（可指定阶数） |
| 极限计算 | `math_sympy_limit` | 边界行为 |
| 量纲分析 | `research_verification_formal(check="dimensional")` | 物理量纲 |
| 量纲传播推演 | `math_sympy_dimension_propagate` | 符号表达式未知量纲推导 |
| 渐近估计 | `math_asymptotic_estimate` | 主导增长阶 |
| 微积分行为 | `math_sympy_differentiate` / `math_sympy_integrate` | 单调性/凹凸性/积分形式 |
| 方程求解（根） | `math_sympy_solve` | 零点/不动点结构 |
| 同态/同构 | `math_check_homomorphism` | 结构保持关系 |
| 代入特殊值 | `math_sympy_subs` | 特殊点求值 |
| 符号矩阵分析 | `math_sympy_solve` + `math_sympy_expand` | 特征值/秩/条件数分析 |

#### (B) 数值探索

| 操作 | 工具与策略 | 产出 |
|------|-----------|------|
| 符号转数值函数 | `math_sympy_lambdify` | 可调用的数值处理器 |
| 随机采样 | `math_witness_consistency` 批量模式 | 随机参数下的数值值分布 |
| 拉丁超立方采样 | 参数空间划分 + 每区间取代表点 | 系统化覆盖的参数-值表 |
| 结构化网格扫描 | 等距/对数间距采样指定的参数范围 | 全覆盖参数扫描表 |
| 自适应精化 | 在梯度大/曲率高的区域加密采样 | 兴趣区域的精细刻画 |
| 敏感性分析 | 单个参数变化、其余参数固定在典型值的 perturb 实验 | 各参数对输出的影响排序 |
| 边界探测 | 对参数边界（0, ∞, ±边界值, 奇异点）计算函数值 | 异常行为点 |
| 可视化建议 | 基于探索结果建议用户可视化的投影方向 | 建议的图表类型和坐标映射 |

**采样策略选择指引**：

| 参数空间维度 | 推荐策略 | 采样密度 |
|-------------|----------|---------|
| 1D | 结构化网格 + 自适应精化 | 50-500 点 |
| 2D | 结构化网格 + 兴趣区精化 | 50×50 - 200×200 |
| 3D-5D | 拉丁超立方 | 500-5000 点 |
| 5D+ | 随机采样 + 敏感性预筛选 | 2000-10000 点 |

**注意**：
- 数值探索不产生证明——它只提供证据和线索。所有数值发现均标注 `[NUMERICAL_EVIDENCE]`。
- 数值探索必须注明采样范围、密度和随机种子（如适用）。
- 发现异常点（极值/突变/不连续信号）后，建议回到 (A) 用符号方法验证。

#### (C) 猜想生成

从 (A) 和 (B) 的发现中，综合可检验的猜想。按照不同类型的猜想采用不同策略：

| 猜想类型 | 触发条件 | 生成策略 | 工具链 |
|----------|---------|----------|--------|
| **数值恒等式** | 数值提示表达式化简为常数 | ① 级数展开验证 → ② 代入多个随机点 | `math_sympy_simplify` → `math_sympy_subs` |
| **渐近形式** | 级数展开/极限计算得到主导项 | ① 确认主导阶 → ② 猜测余项形式 | `math_asymptotic_estimate` / `math_sympy_series` / `math_sympy_limit` |
| **不等式界限** | 数值显示有上下界 | ① 猜测界限值 → ② Z3 验证小变量域 → ③ 猜测一般形式 | `math_prove_inequality` / `math_witness_consistency` |
| **对称/不变性** | 化简后出现明显的对称模式 | ① 猜测变换群 → ② 数值验证不变性 → ③ 猜测更一般形式 | `math_check_homomorphism` / `math_sympy_simplify` |
| **单调性/凹凸性** | 微分符号不变 | ① 计算一/二阶导数 → ② 验证符号恒定性 → ③ 推广到高维 | `math_sympy_differentiate` / `math_sympy_solve` |
| **推广猜想** | 特例成立，参数受限 | ① 枚举更多特例 → ② 猜测参数化形式 → ③ 验证扩展参数范围 | `math_witness_consistency` |
| **恒等式链** | 两个步骤间存在代换关系 | ① 猜测中间代换 → ② SymPy 验证链传递性 | `math_identity_chain` / `math_sympy_verify` |
| **自动定理证明** | 探索中发现具有潜在可证性的命题 | 用 Z3 自动证明命题（支持蕴含断言和循环证明） | `math_auto_prove` |
| **上下界收紧** | 探索到粗略不等式界需要收紧 | 用 Z3/SymPy 自动收紧数值不等式边界 | `math_tighten_bounds` |
| **同态保持** | 两个结构间有映射关系 | ① 计算映射结构 → ② 猜测同态形式 → ③ Z3 验证满足 | `math_check_homomorphism` |

**猜想置信度标记**：
- **[CONJECTURE]** — 形成中、证据不足的推测
- **[STRONG_CONJECTURE]** — 数值证据充分、多个特例通过验证的猜想
- **[COUNTEREXAMPLE_FOUND]** — 已被 falsify 的方向（记录反例和原因）

#### (D) 猜想评估

在投入形式证明之前，系统评估猜想：

1. **快速 falsify**：在尽可能大的参数空间搜索反例
2. **渐近一致性检查**：猜想中的渐近关系是否与已知行为一致
3. **覆盖密度评估**：评价猜想在已测试空间上的置信度
   - 高 = 参数空间 > 80% 有采样点，无异常值
   - 中 = 参数空间 30-80% 有采样点
   - 低 = < 30% 覆盖或采样稀疏
4. **文献新颖性检查**：搜索该猜想是否已被研究（→ 调用 (E)）
5. **形式化可行性评估**：基于已知工具链判断形式化证明的难度
6. **Promote 决策**：
   - 猜想站住脚且新颖 → 输出正式猜想声明，在本 skill 内使用工具链完成形式化证明
   - 猜想站住脚但已知 → 记录文献引用，标注"已为已知结果"
   - 猜想被 falsify → 输出反例，记录为什么失败，标记探索轨迹 `[FALSIFIED_AT: time][REASON: ...]`
   - 证据不足 → 建议进一步探索或缩小范围

#### (E) 文献调研 — 内置外部调研能力

在当前探索中直接集成外部文献检索，不再推送到 `$research` skill。在探索的每个阶段均可唤起：

| 调用时机 | 查询类型 | 工具 | 产出 |
|----------|---------|------|------|
| (A) 静态分析后 | "这个表达式/函数有没有已知的特殊性质？" | `research_literature_search` / `paperplain__search_research` | 已知结果列表（标注已发现/未发现） |
| (C) 猜想生成后 | "这个猜想是否已经被研究/证明？" | `research_literature_search` / `paperplain__find_paper_by_title` | 文献中是否存在相关定理的判定 |
| (D) 猜想评估时 | "这个方向的已知结论和方法？" | `research_literature_search` / `paperplain__fetch_paper` | 相关定理的引用和摘要 |
| 推广猜想时 | "这个推广方向上有没有已知下限/上限？" | `research_literature_search` | 推广方向的已知边界和已知开放问题 |

**文献调研输出**：

```
## 文献相关性判定
**查询表达式/猜想**：...
**检索源**：arXiv / Semantic Scholar / ...
**结果**：
- ✅ 已知结果：[定理/论文名称 + DOI 或 arXiv ID]（新发现被确认但已知）
- ❌ 未找到匹配：[本性质/猜想在检索范围内未出现]（可能的 new result）
- 🔶 相关但不相同：[相关定理/论文]（提供了背景下限但不是直接答案）
- 📋 方法参考：[文献中可用于进一步探索的方法]
```

**当文献调研发现已知结果时**：
- 如果用户目标是"看是否有新性质"，标记 `[ALREADY_KNOWN]` 并引用来源，探索就此终止（除非用户要求重复验证）
- 如果用户目标是"验证结果"，进入 `$math-verify` 进行对抗式审查

**当文献调研未发现结果时**：
- 标记 `[NO_PRIOR_ART_FOUND]` 但要备注搜索范围和局限性（可能已有非英语/非公开/非电子化文献）

### 探索轨迹管理

对多次迭代的探索会话，推荐记录以下轨迹：

```
## 探索轨迹
### 尝试方向
| # | 方向 | 结果 | 依据 |
|---|------|------|------|
| 1 | $... | FALSIFIED | 反例: $x=2, f(x)=3$ |
| 2 | $... | NUMERICAL_HINT | 50 个随机点通过但未符号验证 |
| 3 | $... | PROMOTED | 已形式化验证 → [猜想声明 ID] |
```

## Hard constraints

> [!CAUTION]
> 适用于本 skill 的所有探索输出。

1. **数值证据 ≠ 证明**：所有非代数推导的结论（仅基于数值采样）必须标注 `[NUMERICAL_EVIDENCE]`，不得声称"已验证"。
2. **猜想 vs 结论**：所有未证明的断言必须称为"猜想"而非"结论"——只有经过严格推导并用 checker 验证后才可称结论。
3. **探测范围透明**：数值探索必须注明采样范围、密度和随机种子（如适用）。
4. **反例优先**：在提出猜想前，优先尝试 falsify 而非 confirm。
5. **从特殊到一般**：不跳跃——从特例/简单情形开始，逐步推广，每一步标注推广的合理性和风险。
6. **不供假阳性建议**：如果证据不足以形成合理猜想，说明为什么，不要强行编造模式。
7. **后端不可用时标注**：若 SymPy/Z3 不可用导致探索不完整，标注 `[BACKEND_LIMITED]`。
8. **文献检索透明**：文献调研结果必须标注检索源、检索式和置信度。`[NO_PRIOR_ART_FOUND]` 不保证实际上不存在文献——仅表示在检索范围内未命中。
9. **探索轨迹不可作假**：每个 falsify 记录必须有具体反例值，不得空口说"已有探索发现"。
10. **(S) 阶段产出不可省略**：必须定义探索范围和评估标准，即使很简单。禁止无界搜索。
